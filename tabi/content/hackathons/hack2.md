Secured **1st Place Winner** at Formula Hacks 2025 by designing and shipping an interactive gaming application within a limited time window.

## Problem

Creating engaging interactive mechanics in short hackathons usually leads to messy state management or poor performance under rapid user inputs.

## Solution

Engineered a lightweight, high-performance event loop driven game engine with responsive controls and minimal rendering overhead.

## Key engineering decisions & Chaos

- Kept game physics & state calculations lightweight to maintain consistent 60 FPS in browser environments.
- **The Hackathon Vibe:** Endless banter with teammates, loud music at midnight, and pure adrenaline when testing game mechanics live.

## Technology stack

- **Core Engine:** HTML5 Canvas, Modern JavaScript
- **Tooling:** Vite, CSS Architecture

## Outcome & Learnings

 Took home **1st Place**. Reinforced the importance of rapid prototyping, scoped feature prioritization, and clean game loop state management under strict time limits.
