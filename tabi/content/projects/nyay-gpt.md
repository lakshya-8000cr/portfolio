Nyay-GPT is an AI-assisted legal information platform for conversational legal queries, Indian case-law discovery, document analysis, and persistent chat workflows.

> Nyay-GPT is for informational assistance only and does not constitute legal advice.

## Highlights

- Conversational legal chatbot
- Indian case-law and legal document retrieval
- Email/password and Google authentication through Firebase
- Saved chat history
- Responsive React interface
- Configurable AI-provider integrations
- Support for OpenAI, Groq, and Omni-DIM integrations
- Extensible provider architecture

## Stack

- React
- Vite
- Tailwind CSS
- Firebase Authentication
- Firestore
- Node.js
- Express
- Mongoose-backed data models
- OpenAI, Groq, and Omni-DIM integrations
