MechVerse is an interactive browser-based automotive design sandbox that pairs 3D visualisation with immediate feedback for component changes.

## What It Does

Users can adjust vehicle components in the browser and explore how those changes affect the overall build through visual and physics-oriented feedback.

## Key Features

- Interactive 3D automotive design sandbox
- Component customisation workflow
- Physics-oriented feedback for design decisions
- Immediate visual feedback during iteration
- Browser-based interactive experience
- Wireless smartphone control through Monect PC Remote
- Gamepad-style input using a phone on the same network

## Phone Control

MechVerse supports wireless phone-based control through Monect PC Remote.

1. Install Monect PC Remote Receiver on the PC.
2. Install Monect PC Remote on the mobile device.
3. Connect both devices to the same Wi-Fi network.
4. Connect the mobile app to the PC receiver.
5. Select or configure a gamepad layout.
6. Map forward, backward, left, and right controls.
7. Launch MechVerse and use the phone as a wireless controller.
