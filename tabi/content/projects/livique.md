Livique is a complete e-commerce website developed as a freelance client project.

## Problem

The client needed a modern e-commerce presence that could present products clearly and support a smooth shopping experience across desktop and mobile.

## Solution

A full storefront was built with responsive layouts, reusable UI components, category browsing, product detail flows, checkout handling, and account/order workflows.

## Key Highlights

- Full e-commerce website
- Responsive storefront
- Product catalogue and product-detail experience
- Shopping and purchasing workflows
- Reusable UI components
- Mobile and desktop support
- Client-focused implementation

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
- Express
- Mongoose-backed data models
- Passport Google OAuth
- Cloudinary
- Resend
- Razorpay
- Web Push
